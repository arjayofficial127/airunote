## Template

Wrapped in Joy is an independent reusable organization template using the holiday renderer: ribbons, gifts, and ornaments, with evergreen, cranberry, gold, and ivory colors. The existing Starbucks logo and newly bundled gift SVG need no uploaded files. Admin controls still govern colors, branding/badge, artwork/caption, font, corners, each decoration group, animation, footer, completion message, and sound. The gift illustration itself is a static bundled asset; changing theme colors changes the interface and coded decorations, not that asset's printed colors.

The organization’s existing default template remains Autumn. Applying or editing this holiday template does not alter the source Autumn exam or its saved attempts.
