# Repository Context

Before changing the Airunote landing page, live product demo, registration CTA, or local backend startup behavior, read [`HANDOVER.md`](./HANDOVER.md).

The handover records the approved product direction, implemented interactions, terminology decisions still requiring confirmation, validation already completed, known local warnings, and recommended next work.

Preserve existing uncommitted work. Do not redesign the approved hero/top section or replace the browser-local demo behavior unless the user explicitly requests it.

## Working style: MODE MultiPoint

Use MODE MultiPoint unless the user changes it: inspect the relevant systems first, complete a coordinated implementation pass, then run focused integration and browser smoke tests. Resolve routine issues autonomously and report verified outcomes and remaining deployment limits clearly. This mode does not imply delegation to subagents.
